# Roblox Production Skill

This skill provides production management knowledge for Roblox game development, including templates, workflows, and best practices for shipping games on the platform.

## Contents

- **gdd-template.md** - Comprehensive Game Design Document template with FTUE, HUD breakdown, code redemption strategy, and production milestones
- **liveops-template.md** - Monthly LiveOps proposal template for ongoing content, UGC releases, events, and feature rollouts
- **influencer-campaign-template.md** - Influencer campaign brief with in-game integration, team competitions, and UGC prizing
- **ugc-guide.md** - UGC/Virtual Merch strategy guide with pricing, requirements, distribution methods, and best practices
- **sprint-planning.md** - Sprint/agile workflow patterns for Roblox teams
- **release-checklist.md** - Pre-release, release, and post-release checklists

## When to Use

- Creating or updating Game Design Documents
- Planning LiveOps content calendars
- Designing influencer marketing campaigns
- Planning UGC release schedules
- Creating code redemption strategies (licensed games)
- Planning development sprints and milestones
- Preparing for game releases or major updates
- Tracking project progress and risks
