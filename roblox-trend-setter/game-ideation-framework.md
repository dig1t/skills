# Game Ideation Framework (June 2026)

A systematic approach to generating compelling Roblox game concepts based on market data and proven patterns.

## The TREND Method

### T - Theme Alignment
Identify current cultural trends and themes that resonate:

**Current Hot Themes (Feb 2026):**
- Brainrot/meme culture (TikTok characters)
- Anime (Blue Lock, Jujutsu Kaisen, Kuroko's Basketball, One Piece)
- Cozy/relaxing activities (farming, fishing)
- Atmospheric horror with friends
- Competitive skill expression (FFA, ranked)
- Collection/completion (fish, plants, characters)
- Sports reimagination (arcade/FFA sports)
- Tycoon-combat fusion

**Questions to Ask:**
- What's trending on TikTok/YouTube right now?
- What anime/shows are popular?
- What memes are current?
- What sports/activities are having a cultural moment?
- What genre fusions haven't been tried yet?

### R - Repeatable Core Loop
Define a satisfying, repeatable gameplay loop:

**Proven Loop Patterns (2026):**
1. **Collect → Upgrade → Collect Better** (Fish It!, Bee Swarm)
2. **Fight → Win → Unlock → Fight Better** (Blox Fruits, JJK)
3. **Survive → Progress → Survive Longer** (99 Nights, Evade)
4. **Plant → Wait → Harvest → Trade** (Grow a Garden) ← NEW dominant pattern
5. **Craft → Battle → Upgrade → Craft Better** (The Forge) ← NEW fusion
6. **Deflect → Survive → Outlast** (Blade Ball)
7. **Race → Complete → Unlock → Race Harder** (Obby, Parkour)
8. **Collect Memes → Flex → Raid → Repeat** (Steal a Brainrot)

**Loop Timing:**
- Micro-loop: 5-30 seconds (individual action)
- Session loop: 5-20 minutes (achievement cycle)
- Progress loop: Days-weeks (long-term goals)

### E - Engagement Hooks
Build in mechanics that drive retention and virality:

**Daily Hooks:**
- Daily login rewards
- Daily challenges/quests
- Time-limited events
- Streak bonuses
- Offline earnings (AFK income)

**Social Hooks:**
- Leaderboards
- Trading economy
- Co-op rewards
- Friend bonuses
- Admin abuse events (scheduled chaos)

**Viral Hooks:**
- Shareable clutch moments
- UGC content creation
- Competitive clips
- Meme potential
- "What did YOU get?" randomness

### N - Niche Positioning
Find your unique angle in the market:

**Positioning Strategies:**
1. **Genre Fusion:** Combine two popular mechanics (Tycoon + Combat = The Forge)
2. **Sport Reimagination:** Take one exciting action from a sport, build FFA game (Blade Ball formula)
3. **Theme Twist:** Popular mechanic + unique theme (TD + Gardening)
4. **Quality Gap:** Be the polished version of a rough category (RIVALS for FPS)
5. **Trend Riding:** Be first to capitalize on emerging meme/IP
6. **AFK Economy:** Idle + Trading + Social events
7. **Regional First:** Target underserved markets (Indonesia +700%, LATAM 30M DAU)

### D - Development Scope
Match ambition to resources:

**Scope Tiers:**

| Tier | Timeline | Team | Examples |
|------|----------|------|----------|
| MVP | 1-2 weeks | 1-2 devs | Party game, sport reimagination, obby |
| Small | 2-4 weeks | 2-3 devs | Simple sim, basic horror, casual collect |
| Medium | 1-3 months | 2-4 devs | Fishing sim, tycoon, horror survival |
| Large | 3-6 months | 3-5 devs | Anime fighter, RPG, full TD |
| AAA | 6-12 months | 5+ devs | Blox Fruits-scale, MMO-like |

## Ideation Templates

### Template 1: Sport Reimagination (Blade Ball Formula)

**Formula:** Take [Sport's Most Exciting Moment] + [FFA Elimination] + [Simple Timing Mechanic]

**Requirements:**
- 1-2 button core mechanic
- Natural escalation (speed, count, arena shrink)
- Clip-worthy moments
- Mobile-friendly controls
- Cosmetic monetization surface

**Examples:**
- Dodgeball → deflect ball → **Blade Ball** (proven)
- Archery → aim + deflect arrows → **Arrow Storm**
- Volleyball → dig + spike → **Spike Zone**
- Bullfighting → dodge charging bull → **Toro Royale**
- Sumo → jump over sweeping bar → **Knockoff**

**Key Insight:** Extract the ONE most exciting action. Discard all rules/structure. Build FFA around that moment.

### Template 2: Genre Fusion

**Formula:** [Popular Genre A] + [Popular Genre B] in [Current Theme]

**Hot Fusions (Feb 2026):**
- Tycoon + Combat = The Forge (proven at 300K CCU)
- Idle + Trading = Grow a Garden (proven at 22.3M CCU)
- Horror + Survival + Crafting = 99 Nights (proven at 900K CCU)
- Meme + Obby = Escape Tsunami (proven at 678K CCU)
- Sports + Anime = Basketball Zero / Blue Lock Rivals (emerging)

**Untried Fusions:**
- Horror + Tycoon (build and survive)
- Fishing + Horror (deep sea terror)
- TD + Sports (defend goal with towers)
- Idle + PvP (AFK armies battle)
- Collection + Racing (collect while racing)

### Template 3: AFK Economy (2025's Winning Formula)

**Formula:** [Simple Action] + [Wait/AFK Period] + [Random Mutation] + [Trading Economy]

**Requirements:**
- Action that takes <10 seconds
- Passive growth while AFK
- Random rare outcomes (mutation/weather)
- Player-to-player trading
- Admin abuse events for viral spikes

**Examples:**
- Plant → Wait → Harvest rare mutant → Trade = **Grow a Garden**
- Cast → Wait → Catch rare fish → Trade = **Fish It!**
- Mine → Wait → Find rare gem → Trade = [Untapped]
- Cook → Wait → Create rare dish → Trade = [Untapped]
- Breed → Wait → Get rare mutation → Trade = [Untapped]

### Template 4: Trend Adaptation

**Formula:** Apply [Trending Theme/IP] to [Proven Game Type]

**Current Trends → Game Types:**
- Brainrot memes + anything = viral (short shelf life)
- Anime IP + Fighting/Sports = consistent performer
- Licensed IP + TD = strong (SpongeBob, etc.)
- Horror atmosphere + any genre = engagement boost

### Template 5: Regional Opportunity

**Formula:** [Underserved Region's Interest] + [Proven Roblox Format]

**Examples:**
- Indonesian driving culture + Simulator = Car Driving Indonesia (trending)
- LATAM soccer passion + Anime aesthetic = Blue Lock: Rivals (trending)
- Japanese game culture + Gacha = TD games (trending)

## Validation Checklist

Before developing, validate your concept:

### Market Validation
- [ ] Is the genre/theme currently trending?
- [ ] Are similar games successful (proof of market)?
- [ ] Is there room for differentiation?
- [ ] Can you reach this audience?
- [ ] Is competition low enough to break through?

### Design Validation
- [ ] Can you explain the game in one sentence?
- [ ] Does the first 60–180s convert curiosity into a real session? (First Play Bounce Rate is a NEGATIVE ranking signal under 60s and 61–180s)
- [ ] Is there clear progression?
- [ ] What brings players back on Day 2–7, and again on Day 8–28? (RFY ranking measures play days / playtime / qualified sessions across all three windows)
- [ ] What makes players return to co-play WITH FRIENDS across days? (Intentional Co-Play Days Per User)
- [ ] What earns spend days and Robux spent across the first month? (organic RFY joins only)
- [ ] What makes players tell friends / create clips?
- [ ] Does it work on mobile (60%+ of users)?

### Technical Validation
- [ ] Can you build an MVP in target timeline?
- [ ] Do you have the required skills?
- [ ] Can it run on low-spec phones (Indonesia, Asia)?
- [ ] Can it scale with players?
- [ ] Is the server architecture simple enough?

### Business Validation
- [ ] What's the monetization strategy?
- [ ] Is it ethical monetization (cosmetics > pay-to-win)?
- [ ] How long until profitable?
- [ ] What's the ongoing LiveOps cost?
- [ ] Are there subscription opportunities (no platform fee on renewals)?

### Algorithm context (2026)

**Headline change (rolled out June 15, 2026):** the Recommended For You (RFY) ranker expanded its measurement window from **7 days to 28 days** to reward long-term retention and monetization over short-term hooks. Pitch and evaluate concepts on whether they retain players AND convert them to spend across the full first month — not just the first session or first week.

Three things changed about how Roblox surfaces games that should shape ideation:

1. **Algorithm uses dynamic per-user weighting** — weighting remains dynamic/personalized per user and context, and Roblox still does not publish exact numeric weights or thresholds. But as of June 15, 2026 Roblox now publishes the **relative importance ordering** of ranking signals. Optimize for genre-relative outliers, not absolute thresholds.
	- **Most Important:** Play Through Rate (PTR), First Play Bounce Rate (NEGATIVE), Play Days Per User, Playtime Per User.
	- **Important:** Intentional Co-Play Days Per User, Qualified Play Sessions Per User, Spend Days Per User, Robux Spent Per User.
2. **28-day measurement window** is now live (June 15, 2026). Retention- and monetization-style signals are measured across three periods, reported as separate averages: **Day 1**, **Day 2–7**, and **Day 8–28**. Signals measured across these windows: playtime, play days, qualified play sessions, intentional co-play days, spend days, and Robux spent. The headline click-quality metric is now **Play Through Rate (PTR)** — the rate users play after seeing your game in the RFY sort — with **First Play Bounce Rate** split out separately as a NEGATIVE signal (leaving after a short session, measured at **under 60s** and **61–180s**). "Deep PTR" / QPTR are retired and no longer current named signals. **Playtime Per User is capped at 60 minutes per user, per game, per day**, so the advantage goes to concepts that earn sustained return play across days — not single marathon sessions. Concepts with reasons to come back on Day 2–7 and Day 8–28 (narrative, deep progression, simulation, daily streaks, co-play, trading) are structurally favored.
3. **Standout Games sort** (curated, replaces Today's Picks) actively rewards **novelty** — new mechanics, distinctive visuals, underrepresented genres. Submission via Curation team's nomination form. As of Apr 2026, requires authentic gameplay video on details page.

**Two-stage pipeline (ideation implication):** retrieval selects candidate games — ads, curation, friends, search, and social CAN feed retrieval (get a game *considered*). Ranking then orders them, counting signals **ONLY from users who organically joined from the RFY sort on Home**. Engagement/monetization/retention of users acquired from ads, curation, friends, search, or social is NOT counted in ranking. You cannot buy rank — concepts must earn organic retention.

**Explore → expand (cold start):** a content update can spike new cohorts from recommendations (explore); if a cohort shows good engagement AND monetization, Roblox expands to more such cohorts (expand). Even small cohorts can signal a game is worth considering, so new games are not shut out by the 28-day window — but each cohort earned must be retained across the month.

**Where to verify:** new signals surface in **Creator Analytics → Acquisition → Home Recommendations** (rolling out after the June 15, 2026 announcement). Docs: https://create.roblox.com/docs/discovery . Overview video: https://youtu.be/K7jsk3bzmvE . Webinar: June 17, 2026, 11am PST.

**Metadata best practices that bear on ideation (reaffirmed by the docs):** accurate metadata with no irrelevant keywords; no giveaway/monetary-reward bait in metadata (de-prioritized); unique, original imagery/naming — avoid near-clones and repetitive titles/images; add your own spin to existing trends.

### Monetization context for ideation (2026)

- **US 18+ DevEx +42% bonus** (effective June 8, 2026): spend by age-checked 18+ US players in eligible games earns $0.54 per 100 Robux vs. the standard $0.38.
  - **Eligible: GamePasses, DevProducts, in-game subscriptions, private servers.** **NOT eligible: avatar/Marketplace items.**
  - Requires **R15 avatars**.
  - For older-audience concepts: monetize via your own GamePasses/DevProducts, not Marketplace/avatar items, or you're forfeiting the +42% on every sale.
- **Earnings ad objective** (Ads Manager, May 2026): eligibility-gated by ARPU. Optimizes for users likely to spend. Concepts that pass the ARPU threshold unlock a stronger paid acquisition channel than Maximize Plays.
- **Rewarded Video** does NOT feed the Home algorithm — only IAP Robux spend does. Plan accordingly: don't lean on Rewarded Video as the primary monetization for a game you also want to rank organically.

## Rapid Prototyping Priorities

When building your MVP, focus on:

### Must Have (Day 1)
- Core loop playable and fun
- Basic progression visible
- Mobile-friendly UI and controls
- One session of complete content
- Clear first-minute experience (first 60–180s avoid First Play Bounce Rate, a negative RFY signal — judged separately from deeper session quality)

### Should Have (Week 1)
- Daily login reason
- Social features (leaderboard, friends)
- Basic monetization (1-2 gamepasses)
- Tutorial/onboarding (60%+ completion target)

### Nice to Have (Month 1)
- Events/seasonal content
- Trading system
- Ranked/competitive mode
- UGC elements
- Localization (2x session times)

### Later
- Deep progression tracks
- Subscription tiers
- Admin abuse events
- Cross-promotion
- Regional pricing
- Ad monetization integration

## Pitfall Avoidance

### Don't Do This:
1. **Clone exactly** - You need differentiation
2. **Scope creep** - Ship MVP first, iterate
3. **Ignore mobile** - 60%+ audience on phones
4. **No monetization plan** - Build it in from day 1
5. **Skip testing on low-spec** - Asia-Pacific = 60% of users
6. **Chase dead trends** - Verify current relevance
7. **English-only** - Miss 60%+ of the global audience
8. **Pay-to-win** - Ethical monetization wins in 2026

### Do This Instead:
1. **Innovate on proven formulas**
2. **Define tight MVP scope (1-2 weeks)**
3. **Test on all devices, especially budget phones**
4. **Plan monetization from start (cosmetics + subscriptions)**
5. **Soft launch and iterate based on data**
6. **Check current trend data before committing**
7. **Plan localization early**
8. **Schedule admin/chaos events for CCU spikes**
